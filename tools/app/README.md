# Backport App (test phase)

The Backport Helper with a proper window. Double-click `Backport App.bat` at the top of the repository: a
console window opens (keep it open) and the app opens in your browser. It runs on this PC only.

Everything it does is the helper's own code - the same steps, backups and questions - so the console
helper and the app can be used on the same project. Find searches retail and adds what you tick; Project
lists what you have and removes what you tick; Build & Install shows each step, the preview pictures and
what is installed; Tools has the database clean-up, bring back and the Equip Plus update. "Preview" opens
Wowhead's 3D viewer for that set or item.

Python 3.11+, standard library only (the kit itself still needs numpy and Pillow).
